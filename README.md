# vibe-tools
Vibe Coding 互動網頁
📋 經典賭場拉霸機 規格書（最終更新版）
【角色與任務】 請扮演一位資深的前端工程師，幫我用單一個 HTML 檔案（index.html，內含 CSS 與 JavaScript）寫一個互動式的網頁版「經典賭場拉霸機（Slot Machine）」。請嚴格依照以下的規格書進行開發。

一、基本資訊

技術限制：不需後端，所有畫面、邏輯、動畫與音效觸發皆在單一 HTML 檔內完成。需具備 RWD 響應式設計。

視覺素材：轉輪圖案請直接使用大尺寸的 Emoji（7️⃣, 🎰, 💎, 🍒, 🍋, 🔔）。中獎特效需使用 CDN 引入 canvas-confetti 庫來製作噴灑金幣/彩帶的效果。所有介面文字皆使用英文。

二、畫面佈局與風格

整體風格：經典復古賭場風，深色背景（黑/深紅漸層），外圍帶有閃爍霓虹燈質感的邊框。字體採用像素風（Pixel font）搭配無襯線體。

區塊配置：

頂部 (Paytable)：顯示賠率表，文字標題為「PAYTABLE (MULTIPLIER)」。

中央主體 (Reels)：

3 個並排的轉輪，不需要中間的紅色判定線，也不需要轉輪之間的黑色分隔線。

請使用較粗的外框架框住 3 個轉輪，並在框內使用「上下半透明遮罩（Mask）」的方式，讓畫面的上下部分變暗，自然凸顯正中間那一排的圖案（確保遮罩比例不會過度遮擋中間圖案）。

底部控制區 (Controls)：

CREDIT：顯示目前剩餘籌碼。

BET (CUSTOM)：一個 <input type="number"> 數字輸入框，允許玩家自行手動輸入下注金額。

BET 100 按鈕：點擊後，當前下注額自動 +100（但不能超過目前總籌碼）。

BET MAX 按鈕：點擊後，直接將下注額設定為等於目前所有剩餘籌碼（All in）。

SPIN 按鈕：顯眼的拉霸啟動按鈕。

狀態文字區：顯示「WELCOME TO CASINO」、「SPINNING...」或「WIN X CREDITS!」等提示。

三、遊戲規則與邏輯機制

籌碼與下注：

玩家起始擁有 1000 Credits。

玩家點擊 SPIN 時，系統需先驗證輸入框的數值，若合法則立即扣除對應的 Credit 並開始轉動。若餘額不足或下注額為 0，則無法啟動。

中獎判定（僅單線）：

轉輪停止後，只有停在「正中間」的 3 個圖案一模一樣才算中獎。

賠率表（採下注額乘以倍數計算）：

7️⃣ 7️⃣ 7️⃣：x50 倍

🎰 🎰 🎰：x20 倍

💎 💎 💎：x10 倍

🍒 🍒 🍒：x5 倍

OTHER MATCHES (其他三個一樣的連線，如 🍋🍋🍋 或 🔔🔔🔔)：x2 倍

破產機制 (Game Over)：

當玩家餘額歸零（Credits <= 0）且轉動結束未中獎時，延遲 1 秒跳出滿版的黑色半透明提示畫面。

畫面上顯示大字「GAME OVER」及副標題「Not enough credits to continue!」。

附帶一個「RESTART (Add Credits)」按鈕，點擊後重置網頁狀態並恢復 1000 籌碼。

四、動畫與音效體驗（關鍵核心）

轉動與停止動畫：

按下 SPIN 後，3 個轉輪同時開始高速垂直滾動，圖案帶有垂直模糊殘影效果。

停止節奏：由左至右停止。第 1 轉輪轉動約 1.5 秒、第 2 轉輪 2.5 秒、第 3 轉輪 3.5 秒。

每次轉輪停止時，需伴隨明顯的定格特效（ CSS 彈性回彈/震動效果）。

音效回饋 (Web Audio API)：

停止時發出「喀-喀-喀」的機械音效 (Clack)。

轉動期間有低頻的滾動環境音 (Spin)。

中獎時播放慶祝音效 (Win chime)。

中獎特效：

若判定中大獎（特別是 7️⃣7️⃣7️⃣ 或 🎰🎰🎰），整個拉霸機邊框要切換成「閃爍的金色霓虹燈」CSS 動畫。

觸發 canvas-confetti 在畫面中噴出大量黃色/金色的碎紙（模擬金幣灑落）。

中獎的那 3 個圖案本身要有放大縮小的彈跳動畫（Bounce）。

分數增加時，CREDIT 區的數字必須有平滑快速向上跳動的動畫（Count up 動畫，而非瞬間改變數字）。
